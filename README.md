# تفاصيل | مركز تفاصيل للتدريب

واجهة عربية كاملة ومتجاوبة لمركز تدريب على اختبار القدرات، مبنية على شعار المركز والنقوش الأربع المقدمة. تحتوي على تجربة تدريب تعمل فعليًا، ومساحة متدرب تحفظ التقدم محليًا. لا تحتاج إلى خادم خلفي لتشغيل النسخة الحالية.

## GitHub Pages

رابط الموقع: https://az212z.github.io/tafaseel-training/

يُنشر الموقع من فرع `main` ومجلد `docs/`. بعد تعديل الواجهة، شغّل الأمر التالي ثم احفظ التغييرات وارفعها إلى GitHub:

```bash
npm run deploy:build
```

مجلد `docs/` ناتج مولّد؛ عدّل ملفات `src/` بدل تعديل ملفات النشر مباشرة. يشمل النشر `.nojekyll` وصفحة 404 وروابط أصول نسبية تدعم مسار GitHub Pages.

## التشغيل

يتطلب المشروع Node.js 22.12 أو أحدث.

```bash
npm ci
npm run dev
```

افتح `http://localhost:5173`.

```bash
npm run build
npm run preview
```

افتح `http://localhost:4173` لمعاينة نسخة الإنتاج. ملفات النشر داخل `dist/`.

## ما تم تنفيذه

- رئيسية بهوية المركز وسؤال تفاعلي يعمل مباشرة.
- قائمة برامج مع البحث والتصفية والحفظ، وأربع صفحات لتفاصيل المسارات.
- تدريب مختلط أو كمي أو لفظي، مع شرح الإجابات، ومراجعة النتيجة، واستكمال المحاولة بعد إعادة التحميل.
- مساحة متدرب تعرض النتائج الفعلية على الجهاز، والمسارات المحفوظة، وخطة أسبوعية قابلة للتأشير والتنزيل.
- مكتبة بثلاثة أدلة كاملة وخطة مذاكرة قابلة للتحميل.
- صفحة عن المركز وأسئلة شائعة قابلة للفتح.
- نموذج استفسار يتحقق من المدخلات، ويحفظ مسودة محلية قابلة للتعديل والتنزيل.
- خصوصية استخدام النسخة الحالية، وحذف بيانات المتصفح بتأكيد صريح.
- وضع فاتح وداكن، تنقل بالكيبورد، وترتيب عربي من اليمين إلى اليسار.
- صفحة للمسارات غير الموجودة، ومعالجة تعذر التخزين وقراءة البيانات المحلية التالفة.

## حدود النسخة الحالية

الحفظ في `localStorage` على الجهاز نفسه. لا توجد حسابات مسجلة أو مزامنة أو استقبال طلبات أو دفع أو لوحة إدارة خلفية. زر حفظ الاستفسار يحفظ مسودة فقط؛ لا يرسلها إلى المركز.

المسارات والمحاور والمقالات محتوى تحريري مقترح للتصميم. الأسئلة تعليمية أصلية توضيحية، وليست أسئلة رسمية. لم تُضف رسوم أو مواعيد أو أسماء مدربين أو اعتمادات أو إحصاءات نجاح غير مقدمة من المركز.

## الملفات الأساسية

| الملف                       | الاستخدام                                                      |
| --------------------------- | -------------------------------------------------------------- |
| `src/data/content.ts`       | البرامج، المحاور، الأسئلة، الشروحات، المقالات والأسئلة الشائعة |
| `src/pages/`                | صفحات الموقع وتجارب المتدرب                                    |
| `src/components/Shared.tsx` | التنقل، الهوية، التذييل، بطاقات البرامج والعناصر المشتركة      |
| `src/services/learning.ts`  | أنواع البيانات والتحقق منها والحفظ المحلي والتنزيل             |
| `src/services/context.ts`   | واجهة الحالة المشتركة بين الصفحات                              |
| `src/App.tsx`               | المسارات، الحالة العامة، الإشعارات ومعالجة الأخطاء             |
| `src/styles.css`            | النظام البصري والتجاوب والوضع الداكن                           |
| `public/brand/`             | الصور الأصلية ونسخ WebP المحسنة للويب                          |

الصور الأصلية محفوظة دون تعديل. نسخ WebP تحافظ على المحتوى والنسب والألوان؛ التغيير في الحجم والترميز فقط. الخط مستضاف محليًا، ولا يستخدم الموقع طلبات إلى خدمات خطوط خارجية.

## إضافة الباك إند

راجع [BACKEND-HANDOFF.md](./BACKEND-HANDOFF.md). الحفظ معزول في طبقة خدمات لسهولة الاستبدال. المسارات تستخدم `HashRouter` لعمل النسخة على استضافة ثابتة أو داخل مجلد فرعي؛ يمكن الانتقال إلى مسارات خادم أو SSR عند تطوير الخلفية واحتياجات فهرسة الصفحات المستقلة.

قبل الإطلاق الرسمي، أضف بيانات المركز المعتمدة، ومواعيد ورسوم البرامج، وقنوات التواصل، ثم اربط التسجيل والطلبات بالحسابات والخدمات الفعلية.
