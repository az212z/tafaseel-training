# مركز تفاصيل للتدريب

موقع عربي RTL للدورات التدريبية، بهوية المركز الأصلية، ونموذج حجز عبر واتساب، ولوحة إدارة مرتبطة بقاعدة بيانات مستقلة.

- الموقع: https://az212z.github.io/tafaseel-training/
- نموذج الحجز: https://az212z.github.io/tafaseel-training/#/booking
- الإدارة: https://az212z.github.io/tafaseel-training/#/admin
- دخول الإدارة: https://az212z.github.io/tafaseel-training/#/admin/login
- المستودع: https://github.com/az212z/tafaseel-training

## الدورات والحجز

13 دورة تعريفية ضمن أربعة مجالات: الاختبارات التعليمية، اللغة الإنجليزية، التطوير الذاتي والمهني، والفنون والتصميم. لكل دورة صورة أصلية ومحاور ومهارات وفئة مستهدفة ومتطلبات بداية، ولكل مجال صفحة مستقلة. أوصاف الدورات وصورها وترتيبها قابلة للتعديل من الإدارة.

الاتصال وواتساب: **0558815053**. تفتح أزرار الحجز نموذجًا يطلب الاسم والجوال والدورة، مع بريد ومدينة وملاحظات اختيارية. عند المتابعة، تُفتح رسالة واتساب ببيانات النموذج ليراجعها الزائر ويرسلها. الحجز معتمد بعد تأكيد المركز في المحادثة. لا تُحفظ بيانات النموذج في قاعدة البيانات أو التخزين الدائم للمتصفح، ولا يُرسل الطلب تلقائيًا.

إنستقرام وسناب شات جاهزان بإعدادات فارغة وحالة «قريبًا»؛ تُضاف الروابط في `src/services/contact.ts` عند توفيرها.

المقارنة المرجعية: [COMPETITOR-REVIEW.md](COMPETITOR-REVIEW.md). أغلفة الدورات ونصوص توليدها: [COURSE-IMAGE-PROMPTS.md](COURSE-IMAGE-PROMPTS.md).

## تجربة الزائر

تصفّح المجالات والدورات، حفظ الدورات على الجهاز، مكتبة وتدريب تفاعلي، وتعبئة نموذج الحجز. أُزيل تسجيل الدخول وإنشاء الحساب من الواجهة العامة؛ الروابط القديمة `/login` و`/register` تنتقل إلى الحجز. يختار رابط الدورة الحقل المناسب تلقائيًا عبر `/booking?course=ielts` مثلًا. يدعم الجوال الأرقام العربية والإنجليزية والصيغ السعودية المحلية والدولية.

## الإدارة

لوحة بأرقام فعلية للمتدربين والكورسات النشطة وطلبات القبول والتحصيل. بحث بالاسم والبريد والجوال وتصفية الحالة وتصدير CSV، ملف لكل متدرب، إضافة الحسابات وإعادة تعيين كلمة المرور، إدارة الكورسات والدروس والمرفقات ودفعات التدريب وسعتها، قبول التسجيلات، مطالبات وأقساط وسجل سداد، إعلانات وردود داخل الحسابات، وسجل عمليات محمي.

## التقنية

React 19، TypeScript، Vite 8، Supabase Auth وPostgreSQL وStorage وEdge Functions. تنسيق CSS خاص بالهوية، IBM Plex Sans Arabic، Phosphor، مظهر فاتح وداكن، وإتاحة للجوال ولوحة المفاتيح. HashRouter يبقي روابط الصفحات متوافقة مع GitHub Pages.

## التشغيل

يتطلب Node.js 22.12 أو أحدث.

```sh
npm ci
cp .env.example .env.local
# أضف المفتاح العام لمشروع Supabase في .env.local
npm run dev
```

```sh
npm run lint
npm run build
npm run preview
npm run deploy:build
```

`docs/` مخرجات النشر المولدة. يتم نشرها عند دفع تحديثها إلى `main`. مسار الحسابات والخدمات الخلفية منفصل عن استضافة GitHub Pages، ولا يحتاج تشغيل خادم محلي بعد النشر.

## حدود الخدمات الحالية

الدليل والإدارة متصلان بقاعدة البيانات. بيانات الحسابات والدروس السابقة محفوظة، مع قصر مدخل تسجيل الدخول على الإدارة في مسارها الخاص. المدفوعات متابعة للتحصيل الذي تسجله الإدارة، ولا تنفذ دفعًا إلكترونيًا أو استرجاع أموال. إرسال البريد التلقائي غير مفعّل. الكورسات تحتوي مواد تمهيدية قابلة للتعديل، وتضيف الإدارة بقية محتواها ومواعيدها وأسعارها.

بيانات أول دخول للإدارة محفوظة محليًا خارج المستودع. لا تنشر أي ملف من `.secrets/` أو أي مفتاح خدمة.
